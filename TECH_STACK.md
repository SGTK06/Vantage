# Chosen Tech Stack

## Frontend

**React** chosen for frontend

## Backend

**FastAPI** chosen for backend

## Database + Auth

**Supabase** chosen for file storage, database, and authentication

## Deployment

**Render** chosen for Web Application Deployment

## Third-Party Tools

**LlamaParse** for running PDF-Data-Extractiona dn OCR
**Gemini-embedding-001** for representing product categories as embedding vectors (For semantic comparison and similarity search)
**Gemma-31B** LLM for creating new categories to assign to invoice items (Since this task is trivial a fast and efficient model is used which is sufficiently powerful for the given task)
